  - `Offline-AirGapped-Simulator` — the offline validation VM (see §1.3)
- **Hyper-V virtual switches:**

  - `Offline-Lab` — internal-only switch connecting OR-STT and the offline VM on `10.10.10.0/24`

**OpenSSH Server setup performed this session** (was not installed originally):
```powershell
Add-WindowsCapability -Online -Name OpenSSH.Server~~~~0.0.1.0
Start-Service sshd
Set-Service -Name sshd -StartupType Automatic
```
**Known gotcha:** the auto-created firewall rule from this install is scoped
to the **Private** network profile only. If the Legion's active network
profile is **Public** (check with `Get-NetConnectionProfile`), SSH will still
be unreachable from outside even though the service runs fine locally. Fix:
```powershell
netsh advfirewall firewall add rule name="OpenSSH-Server-In-TCP" dir=in action=allow protocol=TCP localport=22
```
(no `profile=` argument means it applies to all profiles — this is what
actually fixed it this session).

**SSH key auth setup performed this session:**
- Keypair generated on OR-STT: `~/.ssh/legion_key` (private) / `~/.ssh/legion_key.pub` (public)
- Public key installed on the Legion at `C:\Users\it\.ssh\authorized_keys`
  (standard-user path; if `it` turns out to be an administrator account,
  Windows instead requires `C:\ProgramData\ssh\administrators_authorized_keys`
  with restricted ACLs — see `icacls.exe` commands used earlier if needed)
- Connect with:
  ```
  ssh -F /dev/null -i ~/.ssh/legion_key -o ConnectTimeout=5 it@<CURRENT_LEGION_IP>
  ```
- Default remote shell is **cmd.exe**, not PowerShell or bash:
  - Use `&` not `;` to separate commands
  - To run PowerShell/Hyper-V commands: wrap in `powershell.exe -Command "..."`

### 1.3 Offline Validation VM — "Offline-AirGapped-Simulator"

- **Hostname:** `Offline-AirGapped-Simulator`
- **IP:** `10.10.10.2`, static, **persistent** NetworkManager profile (not a transient `ip addr add`)
  - Netmask: `255.255.255.0` (/24)
  - Gateway: none (intentionally — isolated internal network, no routing needed)
  - Interface name: `eth0` on this VM (unlike OR-STT, this VM has only one NIC)
- **OS:** Debian 13 (trixie), amd64, full desktop install (GNOME or similar — has X11 sessions, NetworkManager, standard desktop services)
- **User:** `abbass`, sudo-enabled (password required every time, no NOPASSWD rule)
- **Password (both `abbass` and `root`):** `P@ssw0rd`
- **Network isolation:** genuinely no internet access — confirmed repeatedly via `curl` timeouts
- **SSH access:** password auth, reachable directly at `10.10.10.2:22`

**Connecting (from OR-STT):**
```bash
# One-time: create a bypass config (system ssh_config is broken, see §1.2)
cat > ~/.ssh/config_validation_vm << 'EOF'
Host offline-validation-vm
    HostName 10.10.10.2
    User abbass
    StrictHostKeyChecking accept-new
    ConnectTimeout 5
EOF
chmod 600 ~/.ssh/config_validation_vm

# sshpass needed for password auth — not installed system-wide (no sudo);
# extracted directly from the .deb without installing:
#   apt-get download sshpass
#   dpkg-deb -x sshpass_*.deb <extract_dir>
#   binary at <extract_dir>/usr/bin/sshpass
# NOTE: if working in a fresh session, this extraction must be redone —
# it lived under /tmp/claude-*/scratchpad/ which does not persist.

SSHPASS='P@ssw0rd' sshpass -e ssh -F ~/.ssh/config_validation_vm offline-validation-vm "<command>"
```

**Running commands that need `sudo` on this VM (password required each time):**
```bash
SSHPASS='P@ssw0rd' sshpass -e ssh -tt -F ~/.ssh/config_validation_vm offline-validation-vm \
  'echo "P@ssw0rd" | sudo -S -v 2>/dev/null && <your sudo commands here>'
```
The `-tt` forces a pseudo-terminal (needed for sudo's session/credential
caching to behave correctly over SSH), and `sudo -S -v` primes the credential
cache once so subsequent `sudo` calls in the same script/session don't
re-prompt (cache lasts ~15 minutes).

## 2. Hyper-V Snapshot / Golden Snapshot

- **Correct baseline:** `GoldenSnapshot-WithNetwork`, created **2026-07-09
  11:27:25**, on VM `Offline-AirGapped-Simulator`. Contains: clean Debian 13
  desktop, no Docker, no prior release artifacts, static IP 10.10.10.2/24
  **persistently** configured, no internet.
- **Do NOT use:** the auto-generated `Automatic Checkpoint - Offline-AirGapped-Simulator - (7/9/2026 - 8:59:22 AM)` — this predates the network configuration; reverting to it leaves the VM with no working network and requires manual reconfiguration through the Hyper-V console.

**Reverting via remote PowerShell (from OR-STT, once Legion SSH is set up per §1.1):**
```bash
ssh -F /dev/null -i ~/.ssh/legion_key -o ConnectTimeout=5 it@<LEGION_IP> \
  "powershell.exe -Command \"Restore-VMSnapshot -VMName 'Offline-AirGapped-Simulator' -Name 'GoldenSnapshot-WithNetwork' -Confirm:\$false; Start-VM -VMName 'Offline-AirGapped-Simulator'\""
```
Then wait for `10.10.10.2` to respond to ping (can take 30–90s to fully boot)
before attempting SSH.

**Taking a new checkpoint** (e.g. after fixing something and wanting a new baseline):
```bash
ssh -F /dev/null -i ~/.ssh/legion_key it@<LEGION_IP> \
  "powershell.exe -Command \"Checkpoint-VM -VMName 'Offline-AirGapped-Simulator' -SnapshotName '<NewSnapshotName>'\""
```

## 5. Key Lessons / Bugs Fixed This Session

1. **`apt-cache depends --recurse` manual closures are unreliable** — missed
   Obsidian's own direct dependencies (`libgtk-3-0`, `libatspi2.0-0`) entirely
   in one pass, and separately pulled in two mutually-conflicting alternative
   packages (`opensysusers` vs `systemd-standalone-sysusers`) in another. Fix
   adopted: a **real curated local APT repository** (built with
   `dpkg-scanpackages`) so the target's own `apt` solver resolves dependencies,
   not a hand-computed list.
2. **`apt-get install -s` (simulate) does not catch file-path/fetch bugs** —
   only validates the dependency graph. A real (non-simulated) install or at
   minimum `--download-only` is required to catch path/encoding bugs.
3. **`apt-get download` can produce percent-encoded filenames** (literal
   `%3a` for epoch colons) that break `dpkg-scanpackages`'s `Filename:` field
   unless renamed to their decoded form first.
4. **Flat-repo APT format** requires `Packages`/`Packages.gz` at the
   **repository root**, not inside the `pool/` subdirectory — `Filename:`
   entries are relative to the root (e.g. `pool/foo.deb`).
5. **`--no-install-recommends` matters** — without it, `apt-get install` pulls
   in Recommends not present in the curated repo, causing a silent fallback to
   the (production-unreachable) internet sources.
6. **Debian's t64 transition** renamed many packages (e.g. `libgtk-3-0` →
   `libgtk-3-0t64`); upstream non-Debian `.deb`s (like Obsidian's) built
   against the old names need a compatibility shim package on Debian 13.
7. **Hyper-V automatic checkpoints can predate manual config changes** —
   always verify what a checkpoint actually contains before trusting it as a
   baseline; prefer an explicitly-named, deliberately-taken checkpoint.
